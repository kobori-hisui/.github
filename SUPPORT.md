# Getting Help

Thanks for using our projects. Here is where to go depending on what you need.

| You want to... | Do this |
|---|---|
| Learn how something works | Read the repository `README` and the `CHANGELOG`. |
| Ask a question | Search the existing issues and discussions first. If GitHub Discussions is enabled on the repository, ask in **Q&A**. |
| Report a bug | Open an issue with the **Bug report** form. |
| Request a feature | Open an issue with the **Feature request** form. |
| Report a security problem | Follow [SECURITY.md](SECURITY.md). Do not use public issues. |

## Before opening a bug report

- Update to the latest version.
- Check `chrome://extensions` → **Errors** (or the browser console) and copy any error message.
- Say which browser and version you use, and the exact page where it fails.

Issues without enough information to reproduce the problem may be closed until more details are provided.

This is open source maintained in spare time. Responses are best effort and there is no guaranteed response time.
